# Cocos DevTools 使用說明

這份說明會在 `bun run build` 時**原樣複製一次**到 `dist/說明檔案.md`，不壓縮、不打進 `index.js`。載入未封裝擴充時，可直接在 `dist/` 裡開啟本檔。

## 1. 安裝

1. 在倉庫根目錄執行 `bun run build`（會產生／更新整個 `dist/`）。
2. Chrome 開啟 `chrome://extensions` → 開發人員模式 →「載入未封裝項目」→ 選 `dist/`。
3. 之後若只改對照表或本說明，仍需再 build 一次，或手動把檔案拷進已載入的 `dist/`，然後在擴充頁按「重新整理」。

## 2. 開啟與關閉

工具列圖示**左鍵無作用**；請**右鍵**圖示開啟選單：

- **便條紙**（核取方塊）：顯示／隱藏全站便條 UI（會記住；預設開啟）。頁內藍色浮動鈕可開關設定面板。
- **開啟／關閉 Cocos DevTools**：在 Cocos Creator **瀏覽器預覽**頁（需有 `window.cc`）開啟或關閉除錯視窗。
- **視窗模式**（會記住，預設為子母畫面）：
  - **子母畫面**：Document PiP，置頂、幾乎無外框（類似 YouTube 子母畫面；位置由系統決定）。選單觸發後預覽頁會出現遮罩，**再點一下畫面**才真正開啟（瀏覽器強制要真實手勢）；Esc 取消。
  - **泡泡模式**：一般獨立彈窗（可記住位置與大小）。
- 關掉 DevTools 視窗的 X：同樣視為關閉。
- 預覽重新整理或下次再開同一個網域：若先前是開啟狀態，等引擎初始化後會自動再開（子母畫面同樣會先出現點擊遮罩）。
- 用選單或 X 關掉之後，該網域不會再自動開啟。

彈窗被瀏覽器攔截時，請允許該預覽站點的彈出視窗。子母畫面失敗時**不會**退回泡泡，請看預覽頁主控台錯誤。`file://` 頁面需在擴充詳情勾選「允許存取檔案網址」。

## 3. 屬性表（載入 dist 後自行補充）

屬性面板的**標題、群組、顯示哪一個 key、值怎麼呈現、點擊打印**都來自獨立 JSON，**不經 JS 壓縮**。程式只解讀這份表。

| 階段 | 路徑 |
| ---- | ---- |
| 出廠範本 | `packages/cccdev-template-3x/extension/assets/prop-labels.json` |
| 使用者補充（載入擴充後改這裡） | `dist/assets/prop-labels.json` |

- 只改 **`dist/assets/prop-labels.json`**：存檔後**重開 DevTools 彈窗**即可（必要時在 `chrome://extensions` 重新整理擴充）。不必改程式、不必 rebuild。
- 再執行 `bun run build` 會用出廠範本**覆蓋** dist 這份檔。要永久保留請把內容抄回出廠路徑再 build。

### 格式

值可以是字串（只改標題），或物件（標題 + 呈現 + 打印）。

```json
{
  "cc.Node": {
    "$name": "節點",
    "$groups": [
      { "label": "座標", "keys": ["x", "y", "z"] },
      { "label": "縮放", "keys": ["scaleX", "scaleY", "scaleZ"] }
    ],
    "nodeName": "名稱"
  },
  "cc.Sprite": {
    "color": "顏色",
    "spriteFrame": {
      "label": "圖集幀",
      "display": "name",
      "print": true,
      "show": true
    }
  },
  "MyPlayer": {
    "$name": "玩家",
    "hp": "生命"
  },
  "*": {
    "color": "顏色"
  }
}
```

| 欄位 | 含義 |
| ---- | ---- |
| `$name` | 元件面板標題 |
| `$keys` | 白名單：只顯示列出的 key，順序即顯示順序（適合 Widget / Layout 精簡欄位） |
| `$groups` | 同一行等分。可加 `cells` 當格標（如 `["上","下","左","右"]`） |
| `enum` | 選項陣列 `{ "name", "value" }`；未填則從引擎 `__attrs__` 辨識下拉 |
| 字串 | 該 key 的列標題 |
| `label` | 列標題 |
| `display` | 相對該屬性取值的點路徑（如 `name`、`_name`）。沒設則試 `name` / `_name` |
| `print` | `true`：點擊顯示文字時，把**屬性本體**印到預覽頁主控台（`tempN`），不是印 name 字串 |
| `show` | `true`：即使預設過濾會丟掉（資源物件等）仍顯示 |
| `*` | 所有元件共用的後備標題 |

外層鍵為元件類名（`cc.UITransformComponent` 會對到 `cc.UITransform`）。JSON **不能**寫 JavaScript 表達式，也不能發明引擎沒有的屬性。

### 例子：Sprite 圖集幀

表上顯示 `spriteFrame.name`（沒有 name 再試 `_name`）。點擊該值會 `console.log` 整個 `spriteFrame` 並設為 `temp1`。

顏色欄為色票 + hex：不透明顯示 `#RRGGBB`，有 Alpha 顯示 `#RRGGBBAA`。出廠群組：Widget（對齊邊／邊距／置中）、Layout（內距／間距）；兩者以 `$keys` 精簡為常用欄。

## 4. 面板操作

- 左側：場景節點樹；點選節點後右側顯示屬性。
- 右上角 `P`：Profiler。
- 元件列 `>`：把該物件輸出到預覽頁主控台（`temp1`、`temp2`…）。
- 節點列「⊡」：在場景裡短暫標示該節點。

## 5. 建置會複製到 dist 的檔案

每次成功 build，會把擴充靜態檔**各複製一次**到 `dist/`（覆蓋舊檔，不做壓縮打包）：

- `background.js`、`manifest.json`、`icons/`
- `snippet/content.js`、`snippet/styles.css`（便條紙 content script）
- `assets/prop-labels.json`（屬性表，可在 dist 自行補充）
- `說明檔案.md`（本檔）

UI 程式仍由 Vite 打成 `dist/assets/index.js` 與 `style.css`（這兩份會壓縮）。名稱表與本說明不進那包。
